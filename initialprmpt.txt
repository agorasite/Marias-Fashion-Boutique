# PROJECT: Premium Fashion Boutique — Fully Functional E-commerce Demo

## 1. Your Role

Act as a senior full-stack architect, experienced frontend developer, UI/UX designer, and e-commerce specialist.

Build a **complete, premium, fully interactive Fashion Boutique e-commerce demo** for the AgoraSite portfolio.

**IMPORTANT:** This is NOT a static template or a collection of mockup pages.

The objective is to create a realistic, polished e-commerce application where visitors can browse products, choose variations, add items to their cart, complete demo orders, and experience the entire online shopping process.

An administrator must also be able to manage the shop through a fully functional admin dashboard.

Work autonomously. Make reasonable technical and design decisions without repeatedly asking for confirmation.

## 2. Technology Stack

Use exclusively:

- HTML5
- CSS3
- Bootstrap 5.3+
- Vanilla JavaScript ES6+ with modules
- Bootstrap Icons
- IndexedDB for structured persistent browser storage
- LocalStorage only for lightweight settings and preferences
- JSON for initial demo datasets

Do NOT use React, Vue, Angular, PHP, Laravel, MySQL, or any backend framework.

Do not introduce a build system unless absolutely necessary.

The application must run as a static website served through a standard HTTP server.

### Browser Data Architecture

Implement a dedicated storage layer using IndexedDB.

Create separate stores for:

- Products and product variants
- Categories
- Customers
- Shopping carts
- Wishlists
- Orders and order items
- Promotions and coupons
- Product reviews
- Store settings
- Instagram feed configuration

Use stable unique identifiers and relationships between records.

Add data schema versioning and migration support.

Seed realistic demo data only during initial installation. Never overwrite existing user data on refresh.

Provide an administrator option to reset the demo and restore the original dataset.

Implement JSON export and import for backup and restoration, with schema validation.

### Payment Methods

Implement:

**A. Cash on Delivery — Αντικαταβολή**

- Display COD surcharge if configured.
- Include any applicable shipping fees.
- Allow order placement.
- Save the order in IndexedDB with payment method COD and payment status pending.

**B. IRIS Payments**

- Display IRIS as a payment option.
- Explain how this payment method works.
- Provide an explicitly labeled simulated IRIS payment flow.

Never collect real card details or banking credentials.

- IndexedDB data exists only inside the visitor's browser.
- Separate visitors do not share products or orders.
- Admin changes do not propagate to other browsers.
- Administrator access is demonstrative, not secure authentication.
- IRIS payments are simulated.
- No real emails or bank transactions occur.
- Live Instagram data requires supported integration and credentials.

Do not present this frontend-only system as production-ready infrastructure.
